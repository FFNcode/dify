# Dify 工作流系统设计文档

## 一、整体架构

### 1. 后端架构
```
/api/core/
├── workflow/           # 工作流核心引擎
├── tools/             # 工具集成
├── model_runtime/     # 模型运行时
└── orchestration/     # 任务编排
```

### 2. 前端架构
```
/web/app/
├── workflow-design/   # 工作流设计器
├── components/        # 可复用组件
└── services/         # API 服务
```
